# 方法论清单

分析社会事件时按需取用。每条包含：它回答什么问题、典型提问、局限。**不要全部套用**——选 2–3 个最相关的，其余说明为什么不适用，这本身就是分析质量的一部分。

## 1. 长时段与历史比较（年鉴学派传统）

- **回答**：这个现象在更长时间里是什么形态？是延续还是断裂？
- **典型提问**：三十年、一百年前有没有类似结构？当时是如何演化的？哪些是慢变量（人口、地理、技术、文化），哪些是快变量（政策、事件）？
- **局限**：容易把表面相似当成同构；历史类比常忽略条件差异；对突变与新奇现象解释力弱。

## 2. 结构—功能分析

- **回答**：这个安排满足了谁的什么需要？它为什么能持续存在？
- **典型提问**：如果它没有功能早就该消失，那它的功能是什么？谁在维护它？替代方案的代价是什么？
- **局限**：倾向于把现存当作必要，容易滑向"存在即合理"；对冲突与变迁解释不足。

## 3. 冲突论与利益分析

- **回答**：谁获益、谁承担成本、成本被转移给了谁？
- **典型提问**：收益与成本的分布是否对称？谁有谈判能力、谁没有？哪一方的成本被外部化了？
- **局限**：容易把所有动机都还原为利益，忽略观念与制度的独立作用。

## 4. 政治经济学与制度分析

- **回答**：制度约束下各方能做什么？为什么看似更优的方案没有被选择？
- **典型提问**：决策者的约束条件是什么（财政、考核、任期、部门边界）？路径依赖在哪里？改变需要谁的同意？
- **局限**：容易变成"一切都是政治"的单一解释；对执行层面的复杂性常估计不足。

## 5. 激励与信息经济学

- **回答**：规则给了各方什么激励？信息在谁手里、谁无法观察？
- **典型提问**：如果我是当事人，在这个规则下最优行为是什么？委托代理链条有多长？信息不对称、逆向选择、道德风险出现在哪一环？
- **局限**：需要可观察的行为证据；对文化与规范的解释力有限。

## 6. 社会网络与群体机制

- **回答**：信息与影响通过什么渠道传播？为什么类似的个体会做出不同选择？
- **典型提问**：关键节点是谁？同侪效应、从众、阈值效应在这里如何起作用？谁是被排除在网络之外的？
- **局限**：网络数据常常缺失，容易用可见关系代替真实关系。

## 7. 认知与行为偏差

- **回答**：观察者（包括我）为什么会系统性看错？
- **典型提问**：可得性、代表性、确认偏误、锚定、事后归因在这里起了什么作用？媒体框架如何塑造了我的第一印象？
- **局限**：解释"为什么看错"很容易，难的是给出更准的判断；不能用来否定一切证据。

## 8. 复杂系统与反馈

- **回答**：这是不是一个有反馈回路的系统？为什么干预会产生意外后果？
- **典型提问**：有哪些正反馈与负反馈？延迟有多长？有没有临界点与非线性？局部最优是否导致整体恶化？
- **局限**：容易变成"太复杂所以说不清"的托词；必须落到可观察的机制上才有价值。

## 9. 比较政治与跨国对照

- **回答**：其他国家或地区遇到同类问题时的做法与结果如何？
- **典型提问**：对照对象的初始条件与研究对象的差异在哪？结果差异来自制度、发展阶段，还是数据口径？能否移植？
- **局限**：制度移植的失败案例极多；选择对照对象时极易挑选有利案例。

## 10. 法律与权利框架

- **回答**：这件事在规则上合法与否？程序是否正当？谁的权利被侵犯、由谁主张？
- **典型提问**：适用哪条规范？程序要求是什么？争议的可诉路径与救济方式是什么？
- **局限**：合法不等于合理，也不等于有解释力；法律判断需要专业资质，不能替代事实分析。

## 使用顺序建议

1. 先用**历史视角 + 结构视角**定位问题性质（延续还是断裂、属于哪类问题）
2. 再用**利益分析 + 政治经济学**解释为什么是这个结果
3. 用**偏差清单 + 复杂系统**检查自己的判断
4. 最后用**比较视角 + 法律框架**做边界与救济的补充

## 组合使用的常见错误

- 十种方法全用一遍，每种两句话——看起来全面，实际没有解释力
- 用一种框架解释一切（所有问题都是利益，或都是文化）
- 只给出框架名称，不落到具体机制与证据
- 用方法论掩盖证据不足：框架再漂亮，也不能替代"这件事到底发生了什么"
