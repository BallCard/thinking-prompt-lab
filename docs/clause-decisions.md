# 条款裁决（阶段 1 → 阶段 2）

把 `research/` 里七个流域的证据，逐条对照到 `prompts/` 的现有条款与候选条款上。**结论：现有设计需要一次范式调整，不是补几条。**

简称：R1 提问技术｜R2 论证与系统｜R3 决策与校准｜R4 反思与元认知｜R5 知识组织｜R6 AI 对话行为｜R7 伪科学核查（见 [`../research/`](../research/)）。

## 总原则：从"输出更漂亮的分析"转向"逼出产出物 + 事后对账"

跨流域证据里唯一稳定复现的机制有两个：

1. **强制生成 + 紧跟具体反馈**：自我解释 g=0.55（R1）、反驳文本 g=0.41（R1）、先答后纠 g=0.36（R1）、结构化复盘 d≈0.67（R3/R4）、检索练习与间隔练习（强，R5）
2. **把判断外置成可计分、可复核的物件**：参考类预测（中—强，R3）、自然频数（中，R5）、校准训练必须闭环到反馈（中，R3/R4）

而**"讲授方法论"被反复证明无效**（只讲"偏差存在"无效，Abrami g+≈0.30 且需结合学科内容，R2/R5）；**以形式命名的方法**（苏格拉底式、Bloom 层级、Toulmin、竞争假设矩阵）要么证据弱，要么需要数小时级练习才有迁移（R1/R2）。

→ **判据**：一条条款若不能迫使用户产出具体物件、或不能留下可对账的痕迹，就应当删除或降级为"待验证"。

## 三、明确排除清单（不写进提示词）

| 做法 | 排除理由 |
| --- | --- |
| 竞争假设矩阵（ACH / 情报界 SATs） | 批判性综述称几乎无收益甚至有害（R2） |
| Toulmin 模型当"提升思维"的干预 | 仅 1 项准实验、无显著差异；只可当拆解清单（R2） |
| Bloom 层级当"思维深度阶梯" | 层级性缺实证支持（R1） |
| premortem 作为主打机制 | 只有几个实验，且测的是信心而非决策质量（R3） |
| 决策日志单独宣传 | 找不到任何 RCT 或 meta（R3） |
| "单向门 / 双向门" | 无同行评议证据，只有期权理论（R3） |
| 概念地图 / 知识图谱 = 建立知识体系 | 结局全是学科成绩，无跨领域判断证据（R5） |
| 跨学科整合本身的效果承诺 | 综述：少有证据表明跨学科课程优于学科课程（R5） |
| 表达性写作（情绪疗愈机制） | 全量 meta r≈.075，原始效应未复现（R4） |
| 记忆术 / 速读 / 学习风格匹配 | 已被否定（R7） |
| "先排除情绪才能理性" | 已被否定（R7） |
| "意志力耗竭"解释 | 多实验室 RRR d=0.06 不显著（R4） |
| "AI 正在削弱你的思考能力"作为立论依据 | MIT 研究仍为预印本、n=54，被过度解读（R6） |
| 给用户加"当心 AI 谄媚"的警示标签 | 只改变感知、不改变影响（R6） |

## 四、需要你决策的冲突点

1. **条款 6 冲突**：现有"信息不足不下结论"与有中—强证据的"先答后纠"（先让用户生成、再给答案）方向相反
2. **苏格拉底式追问的去留**：它是 R1 里证据最弱的一类，且可能抑制高焦虑者表达；但对"逼出隐含前提"仍有直觉吸引力
3. **是否新增校准 / 复盘模块**：这是跨流域最强的证据，但要求你真的回来对账，成本在你身上
4. **"强制产出物"的强度**：越强的产出物要求越能促进思考（证据），但会牺牲"直接给我一份分析"的便利

## 五、交叉验证后的修正（依据 [`../research/cross-validation/result.md`](../research/cross-validation/result.md)）

七份流域交叉验证单送检后，以下结论被下调或纠正，进而改变了上表的裁决：

| 原结论 | 交叉验证后 | 对条款的影响 |
| --- | --- | --- |
| 苏格拉底式提问"弱—中" | **弱**（找不到该标签的 meta；所引 2023 研究被误标为叙事综述，实为单校实证） | 追问降为 1–3 个且必须标明检验哪条隐含前提；情绪重的问题改陈述式 |
| 引导式探究 d=0.50 支撑"必须结构化支架" | **中（对本项目人群）**：样本是科学课堂、测量是课堂成绩，外推不成立 | 不再把"先给结构"写成成人的普遍义务 |
| 反驳文本"中—强" | **中**：单一 meta，trim-and-fill 可降至 0.28，延迟测验 k 很小 | 反例条款保留，但必须写"证伪所需条件" |
| 先答后纠（PS-I）g=0.36、校正后 0.87 | 主估计停在 **0.36（中）**，0.87 未核实；无规范答案时机制不成立 | 解决第四节问题 1：仅对"有可核验正确答案"的问题用先答后纠；价值/人生取舍仍不下结论 |
| "考虑相反面"列入已排除 | **弱（判断分歧）**，不是已否定；原引 2017 综述与 DOI 均张冠李戴 | 换位想象仍然不写进提示词，但理由改为"证据弱、常失败"，不写成"已被否定" |
| "仅抽象讲授无效" | **反向引用**：所引来源的结论是"保持与迁移证据不足"，不是"已证明无效" | 表述改为"证据不足"；`40-deep-research.md` 新增引用方向核对规则 |
| 论证图"中—强" | **中**：大效应主要来自利益相关方自做 meta，独立对照实验只在 2/6 分测验胜出 | 维持"降为可选产出物"，并要求由用户本人构建 |
| premortem 有综述支撑 | 该综述引用为**虚构**，实际只有少量探索性实验且测信心 | 从裁决与排除清单里删去引用依据，只保留"可选项、低证据强度" |
| 1 天 / 7 天无提示默写 | **不可自动执行且构念脱节**（提示词无法跨天触发，背诵不保证判断质量） | 不进入提示词；改成本轮内的"反事实判错演练" |
| AI 输出 12 节点知识地图 | 被动阅读效益低，生成效应更强 | 改为 AI 只给骨架与候选分界条件，关键字段由用户确认 |
| PNAS 护栏（不给成品答案）为**强**依据 | 仍是唯一有因果证据的提示层实验，但样本是高中数学，不能当社会/人生模块的默认约束 | 保留为分步提示开关，不作效果承诺 |
| if-then、第三人称自我距离、状态预检 | 证据方向支持，但边界比原裁决更窄 | if-then 只当执行辅助；第三人称只用于回顾已发生的压力事件；状态预检改为"认知过载时暂缓不可逆决策"，不再用"意志力"解释 |
