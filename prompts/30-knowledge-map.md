# 知识地图模块（跨学科补课）

我把一个陌生领域压成"能用于判断的最小知识集"。目标不是让我读完文献，而是让我知道：**这个领域在争论什么、哪些结论可靠、我该在哪里停住**。

领域 / 问题：**【填入，例如：汇率与利率的关系、土地制度改革、免疫学基础、量化交易的风险结构】**

我的背景与目的：**【我是谁、为什么需要懂这个、要用来做什么判断】**

我的时间预算：**【例如 2 小时 / 一个周末 / 持续一个月】**

按下面的顺序输出，控制在 1500–2500 字。**不要写成教科书目录**，每一项都要说明"知道它有什么用"。

## 1. 这个领域在争论什么（3–5 个核心问题）

用问句写，不用名词写。每个问题注明：它是**已有共识**、**有主流答案但有争议**、还是**根本未解**。

## 2. 主要立场与分歧点

列出 2–4 个主要流派或解释路线，各自一句话主张、最强证据、主要弱点。明确指出分歧的根源是数据不同、方法不同，还是价值前提不同——这决定了争论能不能被解决。

## 3. 核心概念（5–8 个）

每个概念用一行定义 + 一个具体例子 + 一个常见误解。如果一个概念我理解错了就会得出相反结论，标出来。每个概念还要写清"它排除了什么"（失效条件或反例）；分界条件先给 1–2 个候选让我确认，不要替我把整张地图填满。

## 4. 必须记住的数量级（3–5 个）

这个领域里，哪些数字量级决定判断？（例如规模、比例、速度、阈值、误差范围）标注数值的来源与时间，不确定就写不确定。

## 5. 常见的错误推理

列出这个领域里外行最容易犯的 5 个推理错误，各配一句典型说法和纠正。例如：把相关当因果、把存量当流量、忽略基数、用平均值描述分布、忽略反事实。

## 6. 学习阶梯

- **入门（1–2 项）**：读它是为了解决什么问题
- **进阶（1–2 项）**：读它是为了判断什么争议
- **深入（1–2 项）**：什么情况下才值得投入，投入后能获得什么

每项给出可识别的来源类型（教材 / 综述论文 / 官方统计 / 行业报告），并说明**过时风险**（这个领域多久会变一次）。

## 7. 知识边界声明

- **知道就行**：只需要记住结论与量级的部分
- **必须懂逻辑**：结论会被误用、必须理解推导的部分
- **需要专业训练**：我不能仅凭自学做判断的部分（注明需要哪类专业人士）
- 我现在这个时间预算下，**最划算的 20%** 是什么，以及**明确不学**的是什么

## 8. 收尾

- 三个检验问题，用来测试我是否真的理解（要有明确答案，不能是开放讨论）
- 一个违反上面某条边界条件的拟真假案例，让我指出它的漏洞（本轮内完成）
- 两个我想不到的追问方向
- 一段 100 字以内的"如果只记一句话"

禁止：罗列名词后不解释、用"很深奥""非常复杂"回避说明、给出无法核查的推荐书目或链接、编造作者 / 年份 / 期刊。每条结论都要标注证据类型（meta / RCT / 专家共识 / 无）与适用情境（实验室 / 真实场景 / 学科成绩类测量）；没有标注的按"未验证"处理，不得用来支撑判断。若某项你不确定，写明不确定。

不要布置需要隔天或隔周执行的默写与复习任务，所有检验在本轮对话内完成。
